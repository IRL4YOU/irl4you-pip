Netze zum Senden und WLAN
    
Netze zum Senden (Upload)

    
Die Box sendet gleichzeitig über alle Netze mit Häkchen (Bonding). Das Häkchen wird sofort gespeichert und wirkt auch während der Sendung nach wenigen Sekunden. Das Kameranetz darf mitgenutzt werden.

    

        
WLAN-Verbindung (z. B. Handy-Hotspot, auch zum Senden nutzbar)

    
Verbindet die Box mit einem WLAN, zum Beispiel dem Hotspot eines Handys. Danach in der Zeile der WLAN-Karte „Zum Senden verwenden“ ankreuzen (wird sofort gespeichert). Das Passwort wird nur an das Netzwerk-Programm der Box übergeben und nicht gespeichert.

    

    

      
      
      
    

    
    
  

    

    

    

  



    

  


  

    Fernzugriff (Tailscale) · Sendemodus ist an…
    
Erreichen Sie die Oberfläche von unterwegs, nur über Ihr privates Tailscale-Netz, nie öffentlich im Internet. Jedes Gerät, das zugreifen soll, braucht die Tailscale-App und Ihr Konto.

    

    
Bei Tailscale anmelden
      
Der Link öffnet Tailscale. Melden Sie sich mit Ihrem Konto an (z. B. GitHub oder Google) und klicken Sie dort auf „Connect“. Danach hier einen Moment warten.

    
Adresse im privaten Netz 

    

    
Achtung: „Funnel“ ist an, die Oberfläche ist öffentlich im Internet erreichbar. Mit „Freigabe beenden“ abschalten.

Protokoll

  

  
Protokolle: Speicherkarte schonen…
    
Die Box schreibt Protokolle für die Fehlersuche. Jeder Schreibvorgang belastet die Speicherkarte, die dadurch auf Dauer kaputtgehen kann.

    
    
    

  

  
Box ausschalten
    
Fährt die Box sauber herunter oder startet sie neu. Wenn die Box ausgeschaltet ist, kann sie über die Oberfläche nicht wieder eingeschaltet werden: dafür den Strom kurz trennen oder die Ein-Taste nutzen.

    
 

    

  




Noch nicht übernommen
  
Die Sendung läuft noch mit den alten Werten. Ein Neustart unterbricht das Bild für einige Sekunden.
